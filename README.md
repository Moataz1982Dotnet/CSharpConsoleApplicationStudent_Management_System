                                                                Student Management System

Description
The project involves creating a console or GUI-based system to manage students,
courses, and grades using OOP principles.

Features
1. User Roles
o Admin: Can add, update, and delete students, courses, and grades.
o Student: Can view their grades and enrolled courses.

2. Core Functionalities
o Student Management: Add, update, delete, and view student details
(e.g., ID, Name, Age).
o Course Management: Add, update, delete, and view courses (e.g.,
Course ID, Name, Credit Hours).
o Enrollment System: Enroll students in courses.
o Grade Management: Assign and update grades for students in specific
courses.

3. Reporting
o View all students in a course.
o View a student’s complete academic record.
